# 🌿 Lukhanyiso's Organic Glam

**Handcrafted Skincare | Organic Beauty | South Africa**

Lukhanyiso's Organic Glam is a responsive, multi-page brand website for a natural skincare and wellness brand.  
The site showcases organic products like Carrot Glow Oil, Whipped Shea Butter, Detox Tea, and Hair Growth Oil — all presented in a warm, gold-and-white aesthetic with smooth animations and a mobile-friendly layout.

## 🚀 How to Run Locally

1. **Download or clone** the project folder.
2. Place all HTML, CSS, and image files in the correct structure (see above).
3. Open `index.html` in any modern web browser (Chrome, Firefox, Edge).
4. No build steps or server required — it’s plain HTML/CSS.

---

## 🛠️ Customization Tips

- **Change colors:** Edit color variables in `style.css` (search for `#b79340` for gold, `#fffaf5` for background).
- **Add more products:** Copy a `<div class="product-card">` block inside `.products` container.
- **Update contact info:** Modify WhatsApp number, email, location in `contacts.html`.
- **Replace testimonials:** Edit the `.testimonial` divs inside `about.html`.
